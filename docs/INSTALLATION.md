
## Installation

1. **Clone the repository**
   ```bash
   cd ~/Desktop
   git clone <repo-url> Contactless_Workspace
   cd Contactless_Workspace
   ```

2. **Create conda environment**
   ```bash
   conda create -n handsi python=3.11
   conda activate handsi
   ```

3. **Install Handsi**
   ```bash
   pip install -e .
   ```
