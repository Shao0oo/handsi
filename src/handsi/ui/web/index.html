About

Handsi is a contactless desktop control system using computer vision and gesture recognition. Control your mouse, scroll, and perform actions using hand gestures captured by your camera.

Welcome to Handsi!

It looks like this is your first time using Handsi. Let's get you set up!

1. Permissions

Handsi requires Accessibility permissions on macOS to control your mouse and keyboard.

When you start detection for the first time, you'll be prompted to grant permissions in System Settings.

2. Camera

Make sure your camera is connected and positioned to capture your hand movements.

The camera should have a clear view of your hands with good lighting.

3. Gesture Control

Use the Thumbs Up gesture to enable control, and Thumbs Down to disable it.

Check the Mappings tab to see all available gestures and their actions.

4. Settings

Customize sensitivity, smoothing, and other parameters in the Settings tab.
